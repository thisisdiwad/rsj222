# Prompt: nowy event HERALD

Użyj skilla `herald-narrative-editor`.

Zadanie: napisz i wdroż nowy event JSON zgodny z runtime HERALD.

Najpierw:
1. przeczytaj aktualny handoff;
2. przeczytaj `web-migracja/docs/03-kontrakt-danych-runtime.md`;
3. przeczytaj `web-migracja/docs/04-progression-spine-i-objective-flow.md`;
4. znajdź 2–3 istniejące eventy z tego samego aktu / pokoju / motywu;
5. nie wymyślaj nowych effect types.

Wynik:
- event JSON w `web-migracja/data-mirror/events/...`;
- content sync, jeśli wymagany;
- test lub aktualizacja istniejącego testu;
- krótki handoff.

Tekst:
- II osoba, czas teraźniejszy;
- bez `To nie X. To Y.`;
- ECHO tylko raportuje;
- CISZA jako pełny wybór;
- każda postać zgodna z idiolektem.
