# Checklist — narracja HERALD

## Kanon

- [ ] Nie zmieniono czterech zakończeń.
- [ ] ECHO nie jest antagonistą / terapeutą / avatarem.
- [ ] Limes nie jest prostym triumfem.
- [ ] CISZA jest pełnym wyborem.
- [ ] Anna pozostaje osobą, nie problemem do rozwiązania.
- [ ] Nie wpisano nowej twardej liczby bez źródła.

## Idiolekt

- [ ] ECHO raportuje.
- [ ] Tomasz mówi spokojnie i krótko.
- [ ] Kezia pyta / tnie sucho.
- [ ] Piotr brzmi technicznie.
- [ ] Naomi maskuje emocje danymi.
- [ ] Solomon pyta uważnie.
- [ ] Brigitte mówi przestrzenią.
- [ ] Dawit waży słowa.

## Styl

- [ ] Brak `To nie X. To Y.`
- [ ] Brak `Nie jest X. Jest Y.`
- [ ] Brak `warto zauważyć`, `kluczowe`, `stanowi`.
- [ ] Zdania mają różny rytm.
- [ ] Dialog nie jest ekspozycją.
- [ ] Każdy opis ma konkret zmysłowy albo techniczny.

## Runtime

- [ ] Nie zgubiono `requirements`.
- [ ] Nie zgubiono `effects`.
- [ ] Nie usunięto blue checków.
- [ ] Flagi pasują do konwencji.
- [ ] Event kończy się flagą.
- [ ] Content sync wykonany, jeśli wymagany.
- [ ] Testy przechodzą.
