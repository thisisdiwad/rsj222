# Typy tekstów w HERALD

## Narracja sceny

- II osoba.
- Czas teraźniejszy.
- Tomasz jako punkt ciężkości.
- Jeden akapit niesie jedną chwilę.

Przykład:

```text
Wchodzisz do laboratorium. Ekrany pracują ciszej niż wentylacja, jakby same
programy próbowały nie przeszkadzać Naomi. Na blacie leży pojemnik z ziemią.
Etykieta odkleja się przy rogu.
```

## Dialog

Format:

```text
— Kwestia postaci.
— Druga kwestia — didaskalia małą literą, jeśli potrzebna.
```

Zasady:

- 1–4 zdania;
- brak ekspozycji konferencyjnej;
- jedna kwestia = jeden ruch relacyjny.

## Wybory

Tekst wyboru ma być czynnością albo decyzją, nie streszczeniem psychologicznym.

Dobre:

```text
Wyślij raport bez prywatnego dopisku
Napisz do Anny
Zostań przy terminalu bez słowa
```

Słabe:

```text
Wybierz profesjonalizm zamiast emocji
Pokaż, że Tomasz nadal kocha Annę
Nie podejmuj decyzji
```

## UI copy

Krótko. Operacyjnie. Po polsku.

- `Gotowe.`
- `Nie teraz.`
- `Zapisano.`
- `NOWY CEL: Odbierz raport ECHO`
- `Tomasz zapada w sen.`
- `Dzień misji [N]. Thales leci.`
