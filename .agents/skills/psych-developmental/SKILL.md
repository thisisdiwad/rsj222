# Developmental Psychology

Validates that game design is appropriate for the target age group
and supports healthy psychological development.

## Frameworks

### Erikson's Psychosocial Stages
For ages 6-12 (Industry vs. Inferiority):
- Children are developing a sense of competence
- **CRITICAL:** Never make children feel inferior or stupid
- Celebrate all attempts, not just correct answers
- Avoid public failure states (no leaderboards showing "worst")
- Frame mistakes as learning, not failure

### Gardner's Multiple Intelligences
Engage varied intelligence types across challenges:
- **Linguistic** — Word puzzles, storytelling
- **Logical-mathematical** — Patterns, sequences, counting
- **Spatial** — Maps, mazes, visual puzzles
- **Musical** — Rhythm, sound patterns
- **Bodily-kinesthetic** — Gesture, movement-based input
- **Interpersonal** — Collaboration, social scenarios
- **Naturalist** — Classification, nature patterns

### Executive Function Development
Children ages 6-8 have limited executive function:
- **Working memory:** Hold 3-4 items maximum
- **Clear rules:** State rules explicitly, don't imply
- **Forgiving mistakes:** Allow undo, retry without penalty
- **Visual cues:** Use icons/colors to reduce memory load
- **One task at a time:** Don't require multitasking

### Piaget's Cognitive Development
Concrete Operational Stage (ages 7-11):
- Can think logically about concrete objects
- Can classify and order objects
- Cannot yet reason abstractly or hypothetically
- Understand conservation (quantity stays same despite appearance)

## Validation Checklist

- [ ] No shame or punishment mechanics (Erikson)
- [ ] Multiple intelligence types engaged across challenges
- [ ] Working memory limits respected (3-4 items max)
- [ ] Age-appropriate vocabulary and abstraction level
- [ ] Mistakes are forgiving (undo/retry available)
- [ ] Rules are stated explicitly, not implied
- [ ] No public failure or comparison mechanics
- [ ] Concrete objects used (not abstract concepts) for young ages
