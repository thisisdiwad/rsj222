# Citation standards

Default style for this repository: **APA 7th edition**. Switch on request to
Vancouver (biomedicine), IEEE (engineering/CS), Chicago, or MLA — keep one style
consistent within a document.

## Every citation must carry

- Authors, year, title, venue (journal/conference/publisher), volume/issue/pages
  where applicable, and a **resolvable DOI** (or stable URL / arXiv ID).
- For preprints: the server + ID and an explicit **"preprint, not peer-reviewed"**
  note.

## APA 7 quick patterns

- **Journal article**: Author, A. A., & Author, B. B. (Year). Title of article.
  *Journal Name, Volume*(Issue), pages. https://doi.org/xxxxx
- **Book**: Author, A. A. (Year). *Title of work*. Publisher.
- **Report / body**: Organization. (Year). *Title of report* (Report No. if any).
  Publisher/URL.
- **In-text**: (Author, Year) or Author (Year); direct quote adds a page/locator.

## Anti-fabrication rules

1. Do not invent DOIs, page numbers, or author lists. If a field is unknown,
   leave it blank and flag it — never guess.
2. Confirm each DOI resolves (Crossref) before including it.
3. Match the in-text claim to the specific passage in the source; note the
   section/page you relied on.
4. If a claimed source cannot be located in any database, remove the claim or
   mark it `UNVERIFIED — no retrievable source`.
