# Critical appraisal & reporting-guideline toolkit

Which instrument to use to judge study quality, and which reporting guideline a
study should have followed. Use with the `critical-appraisal` skill.

## Risk-of-bias / quality tools by design

| Study design | Tool | Judges |
| --- | --- | --- |
| Randomised trial | **RoB 2** | randomisation, deviations, missing data, measurement, selective reporting |
| Non-randomised intervention | **ROBINS-I** | confounding, selection, classification, deviations, missing data, measurement, reporting |
| Cohort / case-control | **Newcastle–Ottawa Scale** | selection, comparability, outcome/exposure |
| Diagnostic accuracy | **QUADAS-2** | patient selection, index test, reference standard, flow/timing |
| Systematic review | **AMSTAR-2** / **ROBIS** | protocol, search, RoB handling, synthesis appropriateness |
| Prediction model | **PROBAST** | participants, predictors, outcome, analysis |
| Qualitative | **CASP** checklists | rigour, credibility, relevance |

## Certainty of the body of evidence

**GRADE** — start high for RCTs / low for observational, then rate down for:
*risk of bias, inconsistency, indirectness, imprecision, publication bias*; and
up for: *large effect, dose–response, plausible confounding would reduce effect*.
Report one of **High / Moderate / Low / Very low** per outcome, with reasons.

## Reporting guidelines (what a well-reported study includes)

- **CONSORT** — randomised trials · **PRISMA** — systematic reviews/meta-analyses
- **STROBE** — observational · **STARD / PRISMA-DTA** — diagnostic accuracy
- **ARRIVE** — animal research · **MOOSE** — meta-analysis of observational
  studies · **SPIRIT** — trial protocols · **PROSPERO** — review registration
- **TRIPOD** — prediction models · **CHEERS** — economic evaluations

A study missing key items from its guideline is not automatically wrong, but the
gaps are a quality signal — note them.

## How to use in a review
1. Match each included study to its design and tool.
2. Score/appraise; summarise as an RoB table (low / some concerns / high).
3. Feed the appraisal into **GRADE** for each outcome.
4. Let certainty ratings drive the calibrated language in the report.
