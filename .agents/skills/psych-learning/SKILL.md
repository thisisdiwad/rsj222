# Cognitive & Learning Science

Validates that game design supports effective learning through
evidence-based cognitive and educational psychology frameworks.

## Frameworks

### Bloom's Taxonomy
Map challenges to cognitive levels. Games should progress upward:
- **Remember** — Recall facts (match the flag to the country)
- **Understand** — Explain concepts (why does this happen?)
- **Apply** — Use knowledge in new contexts (solve this problem)
- **Analyze** — Break down information (compare these two things)

### Piaget's Cognitive Development Stages
For children ages 6-8 (Concrete Operational):
- Use concrete objects, not abstract concepts
- Support logical thinking about physical things
- Avoid hypothetical reasoning (too advanced)

### Constructivism (Piaget/Vygotsky)
- Children learn by DOING, not watching
- Every concept needs hands-on interaction
- Build on existing knowledge

### Zone of Proximal Development (Vygotsky)
- Challenges should be just beyond current ability
- Provide scaffolding: hints, partial solutions, examples
- Gradually reduce scaffolding as competence grows

### Dual Coding Theory (Paivio)
- Pair every verbal fact with a visual representation
- Text + image together > text alone or image alone
- Use icons, diagrams, color coding alongside words

### Multimedia Learning Theory (Mayer)
- **Coherence:** Remove extraneous elements (no decorative-only graphics)
- **Spatial contiguity:** Place words near relevant graphics
- **Signaling:** Highlight important information
- **Segmenting:** Break complex info into smaller chunks
- Limit cognitive load: 3-4 items maximum per interaction

### Spaced Repetition
- Revisit concepts across multiple interactions
- Increasing intervals between reviews
- Mix old and new content in later levels

## Validation Checklist

- [ ] Each game mechanic reinforces a learning objective
- [ ] Progression follows Bloom's taxonomy upward (not random)
- [ ] Content uses dual coding (visual + verbal paired)
- [ ] Cognitive load managed (3-4 items max per interaction)
- [ ] Scaffolding provided for difficult concepts (ZPD)
- [ ] Concrete objects used for ages 6-8 (Piaget)
- [ ] Active learning — player DOES things, not just reads
- [ ] Spaced repetition built into level progression
