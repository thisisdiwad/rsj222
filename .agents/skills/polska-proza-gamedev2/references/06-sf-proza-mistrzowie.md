# SF proza — lekcje mistrzów

Baza wiedzy o stylu polskich pisarzy SF. Stosuj te wzorce przy pisaniu i redakcji narracji HERALD.

---

## Stanisław Lem — konkret zmysłowy + składnia naśladuje zjawisko

### Technika 1: Neologizmy z polskich rdzeni

Lem nie wymyśla słów z niczego — buduje je ze znanych polskich morfemów:
`mimoidy, symetriady, asymetriady, długonie, grzybiska, górodrzewy`

Czytelnik rozumie *coś* nawet nie wiedząc dokładnie *co*. To efekt obcości przez rozpoznanie.

Dla HERALD: unikaj anglicyzmów naukowych gdzie można. Twórz polskie nazwy.
- `anomalia progowa` zamiast `threshold anomaly`
- `fałszywa biosygnatura` zamiast `false biosignature`
- `echo biologiczne` zamiast `biological echo`

### Technika 2: Składnia imituje opisywane zjawisko

Gdy opisujesz zjawisko dynamiczne, powolne albo falujące — rytm zdania to naśladuje:

```
[POWOLNE, NARASTAJĄCE — jak ocean Solaris]
„Twór kurcząc się, zwęźlając bądź rozdymając, ciągnął przez zatokę,
wzdłuż całego widocznego horyzontu, wyrastając coraz bardziej za burtę,
póki nie zamknął pełnego koła."

[SZYBKIE, URYWANE — jak awaria]
„Alarm. Reaktor. B-4. Czterdzieści minut."

[SPOKOJNE, PRECYZYJNE — jak raport naukowy]
„Sygnał przychodził co 47 sekund. Jeden bit na transmisję.
ECHO nie wiedziało co z tym zrobić przez pierwsze trzy cykle."
```

### Technika 3: Zmysłowy konkret dla abstrakcji

Nie pisz o kosmosie abstrakcyjnie. Wejdź w zmysły:

Słabe:
```
Kosmos był ciemny i pusty.
Odległość była ogromna.
```

Lem-style:
```
Za iluminatorem nie było nic — absolutnie nic, żadnego pyłu, żadnego odbitego
światła. Słońce jako punkt wielkości gwoździa. Kezia mówiła, że w pewnym
miejscu trasy przestaje wyglądać jak gwiazda, a zaczyna wyglądać jak błąd
w kartografii.
```

## Jacek Dukaj — zderzenie rejestrów + skrót

### Technika 1: Zderzenie rejestrów dla czarnego humoru

Dukaj łączy biurokratyczno-naukowy rejestr z absurdem:
```
„Węgiel charakteryzuje się niewytłumaczalną tendencją do niepostrzeżonej dematerializacji."
```

W HERALD: ECHO może używać tego efektu dla technicznych raportów o ludzkich sprawach:
```
„Wskaźnik morale załogi: 61%. Odnotowano 4 incydenty unikania kontaktu wzrokowego.
Logbook: niezapisane wpisy za ostatnie 14 dni: 3."
```

### Technika 2: Neosemantyzacja — stare słowo, nowe znaczenie

Dukaj daje starym słowom nowe znaczenia kontekstowe bez wyjaśniania.
Czytelnik domyśla się ze scenariusza.

Dla HERALD: `ciche tury` (gdy Tomasz nie rozmawia), `przebudzenie` (tortury budzenia z torporu), `nominalny` (OK w języku ECHO).

### Technika 3: Skrót informacyjny — ufaj czytelnikowi

Dukaj skraca — nie tłumaczy. Rzuca fakty jak granaty.

Słabe (tłumaczące):
```
Program HERALD to pierwszy w historii ludzkości program eksploracji
pozaziemskiej w celu poszukiwania życia na egzoplanetach.
```

Dukaj-style:
```
HERALD-1. Pierwsza misja. Thales. 7 ludzi. 58 lat w jedną stronę.
```

## Andrzej Sapkowski — dialog jako charakterystyka

### Technika 1: Dialog buduje charakter, nie wyjaśnia fabuły

Sapkowski: „Zło to zło. Mniejsze, większe, średnie, wszystko jedno."

Ta linia nie wyjaśnia czym jest zło. Mówi jak Geralt myśli. Jak liczy. Jak upraszcza.

Dla HERALD: każda kwestia postaci musi mówić *coś* o tej postaci, nie tylko pchać fabułę.

Złe (fabularyczne):
```
— Musimy naprawić reaktor, bo inaczej stracimy zasilanie w sektorze B.
```

Dobre (charakteryzujące):
```
— Reaktor traci ciśnienie od tygodnia. Nie powiedziałem, bo myślałem że sam naprawię.
— [Piotr, bez kontaktu wzrokowego]
```

### Technika 2: Ironia przez lakoniczność

Sapkowski tworzy ironię przez kontrast między powagą sytuacji a spokojem wypowiedzi.

```
[Sytuacja krytyczna, Kezia:]
— Kurs korekty: 0.003 stopni. [pauza] Widziałam gorsze.
```

### Technika 3: Wyliczenia jako rytm

Sapkowskie wyliczenia budują rytm i obsesję postaci:
```
„Mniejsze, większe, średnie — wszystko jedno."

[PRZETRWANIE w HERALD:]
„Tlen. Woda. Żywność. Piotr. Naomi. Solomon. Brigitte. Dawit. Kezia.
Dziewięcioro. Nie, siedmioro. Siedmioro żywych."
```

## Wit Szostak — muzyczność frazy

### Technika: Język jako brzmienie, nie tylko znaczenie

Szostak: fraza musi „brzmieć", nie tylko „wyglądać".
Test: czytaj na głos. Jeśli potykasz się — przepisz.

Dotyczy to szczególnie:
- Opisu przestrzeni (korytarze Thalesisa)
- Wewnętrznych głosów Tomasza
- Momentów ciszy i refleksji

### Zasada przyprawy, nie składnika

Silnie wystylizowany język (filozoficzny, poetycki) = intensywna przyprawa.
Przesyt go zabija. CISZA i PAMIĘĆ mogą go używać. ZARZĄDZANIE — nie.

## Zastosowanie w HERALD — quick reference

| Sytuacja | Wzorzec |
|---|---|
| Opis odkrycia na Limes | Lem: zmysłowy konkret + składnia narastająca |
| Raport ECHO o problemie | Dukaj: zderzenie rejestrów, skrót |
| Dialog Piotra o awarii | Sapkowski: charakteryzacja, nie ekspozycja |
| Głos CISZA | Szostak: muzyczność, minimum słów |
| Opis torporu | Lem: zmysły (zimno, mgła, bezdźwięczność) |
| Wewnętrzny monolog PAMIĘCI | Szostak: fraza + Dukaj: skrót |
| Kryzys decyzyjny Tomasza | Sapkowski: lakoniczność + PRZETRWANIE: wyliczenie |
