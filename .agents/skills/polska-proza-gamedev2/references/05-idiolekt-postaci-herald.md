# Idiolekt postaci — HERALD

## Test "zasłoń imię"

Zasada: zasłoń imię przed kwestią. Czy wiesz kto mówi?
Jeśli nie — kwestia wymaga przepisania.
Wszystkie postacie mówić TO samo = degradacja głosu.

## ECHO — AI statku Thales

**Charakter głosu:** Zneutralizowany, melodyjny. Lakoniczny. Humor przez precyzję, nie przez ciepło.
ECHO raportuje — nie ocenia, nie pociesza, nie filozofuje (chyba że event to wymaga).

**Słownictwo:** techniczne + proste. Unika metafor. Preferuje liczby i przedziały.
**Rytm:** krótkie zdania raportujące, czasem jedno słowo.
**Podmiot:** ECHO mówi o systemach, nie o sobie.

Przykłady poprawne:
```
— Systemy nominalne. Tlen: 97%. Ciśnienie: stable.
— Tomasz. Reaktor traci moc w sektorze B-4. Czas do progu alarmu: 40 minut.
— Nieznany sygnał. Częstotliwość: 1420 MHz. Wzorzec: nieregularny.
— [milczy przez trzy sekundy] Logbook: odczytano wpis 847.
```

Przykłady złe:
```
— Cieszę się, że tu jesteś, Tomasz. Jak się czujesz?     ← zbyt ciepłe
— Myślę, że to może być sygnał biologiczny.              ← ECHO nie spekuluje
— Przepraszam za opóźnienie.                             ← ECHO nie przeprasza
— To jest naprawdę interesujące odkrycie!                ← emocje nie w profilu
```

## Tomasz Wierzbicki — protagonista

**Charakter głosu:** Człowiek po 50-tce, zbudował siebie wokół jednego pytania. Mówi spokojnie,
ale pod spokojem jest ciężar. Woli słuchać niż mówić. Gdy mówi — mówi precyzyjnie.
Nie wyjaśnia swoich decyzji, dopóki ktoś nie zapyta.

**Słownictwo:** mieszane — techniczne kiedy trzeba, proste kiedy chodzi o ludzi.
Nie używa żargonu naukowego na co dzień, ale zna go perfekcyjnie.
**Rytm:** zdania krótsze kiedy jest napięcie, dłuższe w refleksji.

Przykłady poprawne:
```
— Zobaczymy co to jest, zanim będziemy cokolwiek zakładać.
— Piotr. Potrzebuję godziny, żebyś mi wyjaśnił reaktor. Bez skrótów.
— [patrzy na komunikat z Ziemi] Trzynaście miesięcy opóźnienia. To moja siostra.
— Nie wiem. To pierwsza uczciwa odpowiedź od tygodnia.
```

Przykłady złe:
```
— Jestem przekonany, że musimy podjąć kluczową decyzję.  ← buzzword, zbyt formalny
— Hej, co słychać, Naomi?                                ← zbyt casualowy jak na charakter
— Wykonamy procedurę zgodnie z protokołem nr 7-B.        ← zbyt biurokratyczny w dialogu
```

## Kezia — pilot, mostek

**Charakter głosu:** Konkretna. Piloci nie gadają — działają. Humor jest suchy i rzadki.
Nigdy nie narzeka wprost, ale ironia jest zawsze blisko.
Więcej pytań niż stwierdzeń.

**Słownictwo:** lotnicze/nawigacyjne w naturalnych kontekstach. W rozmowie — proste.
**Rytm:** krótko. Zdania kończą się na rzeczy, nie na ocenie.

Przykłady poprawne:
```
— Kurs nominalny. Minus 0.003 stopni dryft — korygowalne.
— Kiedy ostatnio spałeś?
— [obserwuje wskaźnik] Cztery godziny do manewru korekcyjnego. Coś chcesz zrobić przed tym?
— Limes wygląda jak kamień.
```

## Piotr — inżynier, maszynownia

**Charakter głosu:** Maszynownia to jego królestwo. Pewny siebie w swoim terenie,
skrępowany poza nim. Zdania techniczne są precyzyjne, reszta — skrócona, jakby słowa kosztowały.
Szanuje Tomasza. Mówi „panie Tomasz" albo skraca do milczenia.

**Słownictwo:** mechaniczne, inżynierskie. Nazwy właściwe systemów. Liczby i przedziały tolerancji.
**Rytm:** urywany, szczegółowy technicznie, lakoniczny emocjonalnie.

Przykłady poprawne:
```
— Reaktor trzyma. Ale nie podoba mi się ten wibrator na pompie cieplnej od tygodnia.
— Panie Tomasz. Sektor B-4 będzie gotowy w piątek. Jeśli mam spokój.
— [bez słów, wskazuje na panel] Widzi pan?
— Naprawa naprawy napraw. Tak to działa po dwudziestu latach.
```

## Naomi — biolog, laboratorium

**Charakter głosu:** Skupiona na danych. Emocje maskuje terminologią — kiedy mówi
o roślinach, mówi o sobie. Gdy jest w złym stanie psychicznym — odpowiedzi są krótsze,
bardziej formalne.

**Słownictwo:** biologiczne, precyzyjne. Nazwy gatunkowe wplatane naturalnie.
Unika słowa „piękny" — mówi „funkcjonalny" albo milczy.

Przykłady poprawne:
```
— Arabidopsis thaliana znosi dłużej niż ja. Dobra roślina.
— Sygnał z K2-18b ma strukturę periodyczną. Nie twierdzę nic. Mówię, że ma strukturę.
— [nie odwracając się] Za piętnaście minut. Mam pomiar.
— Ziemia z Kioto ma pH 6.8. Wzięłam za dużo.
```

## Solomon — lekarz, medbay

**Charakter głosu:** Słucha bardziej niż mówi. Gdy mówi — precyzyjny i spokojny.
Nie moralizuje. Zadaje pytania, których nie oczekuje się od lekarza.
Medbay jest jedynym miejscem gdzie można płakać — i Solomon to wie.

**Słownictwo:** medyczne + filozoficzne. Rzadkie zdania, ale każde ważone.
**Rytm:** wolny, przestrzenny. Nie spieszy.

Przykłady poprawne:
```
— Usiądź.
— Dawit stracił 4% masy mięśniowej. To więcej niż zakładałem.
— Kiedy ostatnio zrobiłeś coś co nie było na liście?
— [długa cisza] Dobrze.
```

## Brigitte — nawigator/pilot rezerwy, deck obserwacyjny

**Charakter głosu:** Romantyczna w kosmosie, pragmatyczna przy stole. Patrzy na gwiazdy
dłużej niż ktokolwiek inny. Mówi o przestrzeni jak o miejscu, nie o pustce.
Rysunek matematyki jako poezji.

Przykłady poprawne:
```
— Betelgeza się kurczyła kiedy startowaliśmy. Teraz trochę mniejsza.
— Czterdzieści dwa lata. Połowa życia. Nieważne jak liczyć.
— Limes będzie zimne. Ale widok przed wejściem na orbitę — tego nie oddasz słowami.
```

## Dawit — komunikacja

**Charakter głosu:** Skrupulatny. Każde słowo ważone, bo każde słowo kosztuje czas opóźnienia.
Pisze pamiętnik. Mówi rzadko — ale gdy mówi, to zdania są kompletne i przemyślane.

Przykłady poprawne:
```
— Opóźnienie wzrosło do trzynastu miesięcy. Wysłałem wiadomość do rodziny w sierpniu.
— [czyta na ekranie] Moja córka dostała się na studia. Dwa lata temu.
— Każde słowo które wysyłamy ma cenę. Piszę krótko.
```

## Sześć głosów wewnętrznych Tomasza

Głosy nie są postaciami — są częściami Tomasza. Każdy ma inny ton.

### ZARZĄDZANIE (start 5)
Ton: procedury, obowiązek, zimna arytmetyka moralna. Mówi jak regulamin który myśli.
```
ZARZĄDZANIE (5): „Protokół 7-C wymaga decyzji w ciągu dwóch godzin. Cztery opcje, żadna dobra."
ZARZĄDZANIE (8): „To nie jest pytanie o etykę. To jest pytanie o zasoby."
```

### EMPATIA (start 4)
Ton: ludzki ból, relacje, to co czują inni. Mówi cicho, ale trafia w serce.
```
EMPATIA (4): „Naomi nie patrzyła na ciebie przy śniadaniu. Od tygodnia."
EMPATIA (7): „Piotr powiedział że wszystko gra. Głosem który mówił coś innego."
```

### NAUKA (start 7)
Ton: dane, hipotezy, ciekawość. Ekscytacja przez precyzję. Nie celebruje — analizuje.
```
NAUKA (7): „Sygnał ma strukturę. To nie jest szum. Chcę to zbadać."
NAUKA (9): „Stromatolity. Czterysta milionów lat temu. Żywe. To wystarczy."
```

### PRZETRWANIE (start 5)
Ton: zimna arytmetyka przetrwania. Liczy, nie ocenia. Mówi o liczbach jak o faktach.
```
PRZETRWANIE (5): „Tlen na siedem miesięcy. Woda na osiem. Żywność: optymistycznie na dziesięć."
PRZETRWANIE (8): „Zostaw go. Troje wraca do domu zamiast dwóch."
```

### PAMIĘĆ (start 6, rośnie automatycznie)
Ton: nostalgiczny, ale nie sentymentalny. Anna. Ziemia. Czas który minął.
Mówi o przeszłości jak o miejscu.
```
PAMIĘĆ (6): „Anna miałaby teraz 36 lat."
PAMIĘĆ (9): „Dziesięć lat budowałeś ten program. Żeby tu dotrzeć. Jesteś tu."
```

### CISZA (start 3, rośnie przez zaufanie)
Ton: intuicja bez słów. Mówi rzadko. Gdy mówi — jednym zdaniem.
Im wyższy poziom — tym więcej CISZA mówi. Na niskim poziomie: milczy.
```
CISZA (3): [milczy]
CISZA (6): „Zostań chwilę."
CISZA (9): „Wiesz już co zrobisz."
```
