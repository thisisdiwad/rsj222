# AI-izmy i kalki — pełna lista telltale

Tekst zawierający wiele fraz z tej listy brzmi jak przetłumaczony z angielskiego lub wygenerowany przez AI.
Każde trafienie nie jest błędem gramatycznym — to **sygnał stylistyczny**. Oceń kontekst.
Jeśli >15% linii dialogu lub narracji zawiera te wzorce → całość wymaga przepisania.

---

## A. Frazy-wytrychy (overused, meaningless)

| Fraza | Dlaczego zła | Alternatywa |
|---|---|---|
| `warto zauważyć` | Pusty wstęp | Pomiń lub napisz co warto zauważyć |
| `warto wspomnieć` | j.w. | Pomiń |
| `nie można zapomnieć` | j.w. | Pomiń |
| `należy podkreślić` | Biurokratyczne | Napisz wprost |
| `to ważne` | Mówi czytelnikowi co ma czuć | Pokaż dlaczego |
| `jest to kluczowe` | j.w. | j.w. |
| `oczywiście` | Patronizujące | Usuń |
| `zdecydowanie` | Nadużywane | `bardzo` / `wyraźnie` / pomiń |
| `w zasadzie` | Niezdecydowane | Usuń lub zdecyduj |
| `właściwie` (jako wzmocnienie) | j.w. | j.w. |
| `realnie` (jako wzmocnienie) | Puste „uwiarygodnienie" — nie precyzuje nic | Usuń lub zastąp konkretem |

## B. Buzzwordy — zakaz absolutny w grze SF

W tekstach gry te słowa = natychmiastowy sygnał AI-prozy:

`innowacyjny, kluczowy, kompleksowy, dynamiczny, przełomowy, rewolucyjny, holistyczny, niezawodny, spersonalizowany, płynny, zaawansowany, optymalny, wydajny, efektywny, istotny (jako przymiotnik wartościujący bez konkretu)`

Zamiast: `„zaawansowany system reaktora"` → `„reaktor który nie toleruje błędów"` / `„reaktor z czterema stopniami zabezpieczeń"`

## C. Kalki angielskie — frazy

| Kalka | Naturalna polszczyzna |
|---|---|
| `to sprawia, że` | `przez to` / `dlatego` / `stąd` |
| `jest to rodzaj X` | `to coś w rodzaju X` / przeformułuj |
| `to jest X, który Y` | `X, który Y` (bez „to jest") |
| `w rzeczywistości` | `naprawdę` / `w istocie` / pomiń |
| `odpowiedź brzmi` | po prostu odpowiedź, bez zapowiedzi |
| `na poziomie emocjonalnym` | `emocjonalnie` |
| `na poziomie X` | `X-owo` / przeformułuj |
| `mówi bez owijania` | `mówi wprost` / `mówi bez ogródek` |
| `nie ma jak wiedzieć` | `nie sposób wiedzieć` / `nie ma sposobu` |
| `jak długo tu jesteś?` | `od jak dawna tu jesteś?` |
| `dobrze go zna` | `zna go dobrze` |
| `przez ten czas` | `przez cały ten czas` / `tymczasem` |
| `jest czymś gorzej` | `jest czymś gorszym` |
| `dedykowany` (zamiast przeznaczony) | `przeznaczony` / `stworzony dla` |
| `nie jest w porządku` | `coś tu nie gra` / `coś jest nie tak` |
| `nie tylko X, ale (przede wszystkim/także) Y` | Rozbij na dwa zdania albo zostaw tylko Y — ten szablon (`not only... but also`) w nadmiarze brzmi jak referat, nie jak mowa |

**Fałszywy kontrast „to nie X, to Y"** — prawdopodobnie *najbardziej* rozpoznawalny
tik GPT-stylu, po polsku i po angielsku. Wzorzec: `To nie X. To Y.` /
`To nie tylko X, to (też/przede wszystkim) Y.` / `Nie chodzi o X, chodzi o Y.`
Brzmi jak objawienie, ale X i Y często wcale nie są przeciwstawne — to czysta
retoryka, sztuczne domknięcie zdania efektowną klamrą.

Złe (czysty AI-tik):
```
To nie awaria. To ostrzeżenie.
To nie tylko gra, to doświadczenie.
Nie szukamy życia. Szukamy odpowiedzi.
```

Dobre (HERALD — konkret zamiast klamry):
```
Wskaźnik B-4 powyżej normy od trzech godzin. [ECHO mówi faktem, nie definicją]
Cofnij się. Coś tu nie gra. [PRZETRWANIE — konkretna instrukcja, nie etykieta emocji]
Szukamy odpowiedzi. [jedno zdanie wystarczy — drugie nic nie dodawało]
```

**Test:** wytnij pierwszą połowę (`To nie X`). Jeśli druga połowa (`Y`) sama
nosi cały sens zdania — pierwsza połowa była tylko ozdobnikiem. Usuń ją.
Jeśli obie połowy faktycznie *są* sobie przeciwstawne i obie niosą informację
(rzadkie, ale możliwe) — zostaw, to nie jest automatyczny zakaz.

## D. Kalki składniowe (szyk zdania)

| Angielski szyk | Polski szyk |
|---|---|
| `On powiedział, że on jest gotowy.` | `Powiedział, że jest gotowy.` (brak zaimków) |
| `Ja myślę, że ty powinieneś.` | `Myślę, że powinieneś.` |
| `To jest coś czego nigdy nie zapomnę.` | `Tego nigdy nie zapomnę.` |

**Ogólna zasada:** W polskim zaimki osobowe (ja, ty, on, ona) pomijamy gdy podmiot wynika z formy czasownika. Ich obecność to sygnał kalki.

**Wyjątek:** Zaimki osobowe dla emfazy są OK: `„To *ja* jestem odpowiedzialny."` (nacisk na „ja").

## F. Cechy strukturalne AI-tekstu (trudniejsze do grep)

Sygnały, które trzeba ocenić ręcznie:

1. **Monotonia rytmu** — wszystkie zdania mają podobną długość (4–8 słów każde).
2. **Domykanie każdej myśli konkluzją** — każdy akapit kończy się mini-wnioskiem: „Dlatego X jest ważne." / „To właśnie stanowi o Y."
3. **Listy zamiast prozy** — narracja zorganizowana jako punkty `•`, nie zdania.
4. **Brak emocji i punktu widzenia** — tekst opisuje, nie odczuwa. Brak napięcia.
5. **Symetria wyliczeniowa** — trzy rzeczy, cztery rzeczy, zawsze tyle samo na poziomie.
6. **Puste wstępy** — pierwsze zdanie akapitu nie mówi nic: „To jest interesujące zagadnienie."
7. **Postaci mówią tak samo** — nie da się rozróżnić Piotra od Naomi po samej kwestii.
8. **Nadmiar zdań z „który/która/które"** — AI rzadko sięga po imiesłów albo prostsze rozbicie na dwa zdania, więc podrzędniki z „który" piętrzą się jedna za drugą. Jeśli trzy zdania z rzędu mają „który" — rozbij część na osobne zdania albo zamień na imiesłów.
9. **Tekst „zbyt zbalansowany"** — brak ostrych krawędzi, ekstremalnych emocji, specyficznych słów. Wszystko brzmi rozważnie i bezpiecznie. To jest dokładnie odwrotność idiolektu — żywa postać ma *swoje* słowa, swoje upodobania, czasem niesprawiedliwe oceny. Zobacz `05-idiolekt-postaci-herald.md`.

## G. Słowa zakazane w dialogach dla konkretnych postaci

### Głosy wewnętrzne (ZARZĄDZANIE, EMPATIA, NAUKA, PRZETRWANIE, PAMIĘĆ, CISZA)
Głosy wewnętrzne nigdy nie używają:
- `„Tomasz, powinieneś…"` (mówią do Tomasza, nie do gracza)
- `„Możesz wybrać…"` (to system, nie głos)
- Buzzwordów i fraz-wytrychy — mają ostry, charakterystyczny ton

### ECHO
ECHO nie używa:
- `„Przepraszam"` (za błąd systemu — ECHO mówi o faktach)
- `„Myślę, że…"` (ECHO raportuje, nie spekuluje — chyba że to narracyjny moment)
- Zdań z podmiotem `„ja"` (ECHO mówi bezosobowo lub o systemach)
- Ciepłych zwrotów: „dobrze", „super", „świetnie" — ECHO jest zneutralizowane
