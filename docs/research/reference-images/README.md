# Materiały obrazowe gier odniesienia

Obie gry są **równorzędną inspiracją** wizualną, zgodnie z decyzją użytkownika z 2026-09-16:
**Ski Jump International 3** wyznacza kamerę, sterowanie i widok z boku, a **Deluxe Ski Jump 2**
dyscyplinę palety, kontrast, cień pod skoczkiem, minimalny HUD i płynność. Szczegóły kierunku
artystycznego są w [AGENTS.md](../../../AGENTS.md).

bierzemy więc paletę, kontrast, cień, minimalizm HUD i płynność, a nie dosłowny sprite zawodnika.

## Prawdziwe skoki (decyzja użytkownika 17.09.2026, runda 4 PKG-008)

Zdjęcia dokumentalne z Wikimedia Commons (obejrzane 17.09.2026, miniatury
~900 px; oryginały na podanych stronach opisu). Służą analizie pozycji
ciała w fazach — tak jak SJ3/DSJ2: **nie umieszczać w `public/`, paczce
assetów ani buildzie gry**. Pozycje zaobserwowane i przeniesione do banku
klatek (patrz REPORT.md PKG-008 §9.7): rozbieg = głęboki kuc (tułów poziomo
nad nartami, głowa nisko z przodu, ręce cofnięte wzdłuż tułowia); lot V =
ciało płasko między nartami, ręce dociśnięte wzdłuż ciała (Red Bull / FIS:
„arms stretched back next to the body", koniec stylu z rękami do przodu);
telemark = wykrok ~1 długość buta, tułów wyprostowany, ręce poziomo
do przodu/góry dla równowagi (Wikipedia „Telemark landing").
